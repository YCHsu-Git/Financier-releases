## 更新紀錄

### v20261102.0055

- 新增：個股頁「基本面與財報」卡片，選到股票時自動顯示公司概況、近四季 EPS、本益比、淨值比、ROE、負債比、流動比、最新月營收（月增、年增、累計年增）、近 5 季損益與最新資產負債；AI 分析也會參考這些財報數字。財報來自 FinMind 公開資料，公司資料來自證交所與櫃買中心，僅供參考。

- 修正：Windows 版設定 GitHub Models 後，個股 AI 分析按鈕可正常使用。
