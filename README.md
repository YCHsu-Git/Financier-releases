# Financier-releases
Financier 執行檔下載（Windows exe、Android APK）；原始碼不公開

## 更新紀錄

### v20261102.0826

- 新增：「選股策略」分頁，第一個策略是長期存股領息（ROE 連續 3–5 年 > 10%、平均殖利率 4–6%、連續 10 年以上配息、近 3 年營業利益率穩定或成長），條件可調整，結果逐項標示符合與否。
- 新增：全球指數點進去可看基本資料、漲跌表現、技術分析（均線、RSI、MACD、突破、形態）、漲跌預測、K 線圖與前 20 大成分股。
- 新增：自選股的「AI 分析建議」與預估漲跌幅、預估價格。
- 改版：K 線圖加入均線、籌碼分布、成交量、RSI、MACD 與十字線，並支援 61 種 K 線形態辨識（可勾選）。
- 新增：排行可切換成方塊圖；AI 設定改為分頁；新聞分頁的「AI 全市場分析」與新聞來源同級。

### v20261102.0255

- 新增：Windows 版可內建 Google OAuth 用戶端（把用戶端 ID 與密鑰放進 `google-oauth.txt` 後重新建置），之後使用者只要按「登入 Google」並選自己的信箱帳號即可同步；沒有內建時仍可在「OAuth 用戶端設定」手動填入。
- 調整：GitHub Models 回傳非 JSON 時，說明改為建議改用 OpenAI、Gemini 或 Ollama。

### v20261102.0245

- 新增：新的 App 圖示（上升的 K 線與趨勢箭頭），Android 與 Windows 版都換了。
- 新增：OpenAI 作為 AI 供應商，用自己的 API 金鑰直接呼叫（預設 gpt-4.1-mini，可換模型）。
- 調整：漲跌預測改成明日、3 日、1 週、1 個月的上漲／下跌機率，記錄每次猜對猜錯與失敗次數，依過去結果自動修正；第一次追蹤會先用歷史資料回測。可在 AI 設定改成由 AI 產生預測（GitHub 只收到去識別的數字），準度依 AI 來源分開記錄。
- 調整：AI 設定的各區塊可摺疊。

### v20261102.0211

- 新增：個股頁「同業比較」，列出同產業的殖利率、本益比、淨值比與成交額，並用規則式評分挑出 3 檔建議（只是估值與配息的相對比較，不是投資建議）。
- 新增：排行合併原本的「股息」分頁，可依殖利率、現金股利、除息日、本益比低、淨值比低排序，並可依產業與價格區段篩選。
- 新增：基本面卡片的獲利來源（本業 vs 業外）與營收去向圓餅圖與說明，以及股利與除息資訊；個股頁新增 0–100 分的綜合風險評估。
- 新增：全球指數與自選股的隔日高低點預測，記錄每次猜對或猜錯，並在列表顯示成功猜測機率與失敗次數（規則式推估，僅供參考）。
- 新增：多 AI 依序辯論，個股 AI 分析在設定兩種以上 AI 時，後面的 AI 逐點同意或反駁前面的結論，每段標記是哪個 AI 的結論。
- 修正：GitHub Models 不接受股票內容，改為只送去識別的純數學題，結論標明為純數學運算。
- 修正：Ollama 逾時延長為 30 分鐘；Windows 版線上更新一直卡在舊版的問題。

### v20261102.0123

- 新增：多 AI 辯論。個股「AI 分析」在設定兩種以上 AI（Gemini、GitHub、Ollama）時，會依序讓每位 AI 發言，後面的 AI 看到前面的結論後逐點同意或反駁，最後一位列出各家共識與分歧；每段結論都標記是哪個 AI 的。
- 修正：Windows 版線上更新一直卡在舊版。v20261102.0055 的 Windows 執行檔其實是舊版建置（內嵌版本標記 20261102.0015，且不含下方「基本面與財報」），請更新到本版。
- 修正：GitHub Models 收到非 JSON 回應時，改為顯示明確的錯誤說明。

### v20261102.0055

- 新增：個股頁「基本面與財報」卡片，選到股票時自動顯示公司概況、近四季 EPS、本益比、淨值比、ROE、負債比、流動比、最新月營收（月增、年增、累計年增）、近 5 季損益與最新資產負債；AI 分析也會參考這些財報數字。財報來自 FinMind 公開資料，公司資料來自證交所與櫃買中心，僅供參考。（Android 版 APK 含此功能；Windows 版自 v20261102.0123 起才有。）
- 修正：Ollama 模型清單可隨時重新抓取、顯示全部模型與錯誤訊息，Windows 版可手動輸入模型名稱（Android 版改為自動換行）。
- 修正：Windows 版設定 GitHub Models 後，個股 AI 分析按鈕可正常使用。
