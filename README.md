# Financier-releases
Financier 執行檔下載（Windows exe、Android APK）；原始碼不公開

## 更新紀錄

### v20261102.0123

- 新增：多 AI 辯論。個股「AI 分析」在設定兩種以上 AI（Gemini、GitHub、Ollama）時，會依序讓每位 AI 發言，後面的 AI 看到前面的結論後逐點同意或反駁，最後一位列出各家共識與分歧；每段結論都標記是哪個 AI 的。
- 修正：Windows 版線上更新一直卡在舊版。v20261102.0055 的 Windows 執行檔其實是舊版建置（內嵌版本標記 20261102.0015，且不含下方「基本面與財報」），請更新到本版。
- 修正：GitHub Models 收到非 JSON 回應時，改為顯示明確的錯誤說明。

### v20261102.0055

- 新增：個股頁「基本面與財報」卡片，選到股票時自動顯示公司概況、近四季 EPS、本益比、淨值比、ROE、負債比、流動比、最新月營收（月增、年增、累計年增）、近 5 季損益與最新資產負債；AI 分析也會參考這些財報數字。財報來自 FinMind 公開資料，公司資料來自證交所與櫃買中心，僅供參考。（Android 版 APK 含此功能；Windows 版自 v20261102.0123 起才有。）
- 修正：Ollama 模型清單可隨時重新抓取、顯示全部模型與錯誤訊息，Windows 版可手動輸入模型名稱（Android 版改為自動換行）。
- 修正：Windows 版設定 GitHub Models 後，個股 AI 分析按鈕可正常使用。
